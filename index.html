Билд 1 «Мгновенный HD-пайплайн». Фото остаются бесплатными. Открой две вкладки сверху: Гид загружает фото → Клиент тут же видит их в галерее по своему номеру гидроцикла.

Что чиним

Сейчас

гид → WhatsApp → админ → вручную в Google Drive. Задержка 1–3 дня, WhatsApp режет качество, всё на одном человеке.

Билд 1

гид → аплоадер → авто-проверка → галерея. Минуты, оригинал, без админа-горлышка.
Что показывает демо
• Гид: простой тайский аплоадер (2–3 тапа: рейс + цвет + номер), грузит оригиналы с iPhone.
• Авто-проверка: рейс/цвет/количество/качество — без ручной раскладки.
• Клиент: тот же общий QR → выбирает день/рейс/цвет → вводит номер гидроцикла → видит свои фото. Номер виден на борде в кадре.
• ✨ AI-поиск по лицу — тизер премиум-фичи (Билд 2).
