What this fixes

Now

guide → WhatsApp → admin → manual upload to Google Drive. 1–3 days delay, WhatsApp lowers quality, everything depends on one person.

Build 1

guide → uploader → auto-check → gallery. Minutes, original HD, no admin bottleneck.
What this demo shows
• Guide: simple Thai uploader (2–3 taps: trip + color + number), sends original photos from iPhone.
• Auto-check: trip / color / photo count / quality — no manual sorting.
• Client: same shared QR → picks day / trip / color team → enters the machine number (visible on the jet ski in every shot) → sees their photos.
• ✨ AI face search — teaser of the premium feature (Build 2).
