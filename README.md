# Phuket Jetski Club — Ops Suite (live demos)

Interactive demos of an internal ops toolkit for a jet-ski tour operator (Phuket, Thailand):

| Demo | What it shows |
|---|---|
| [index.html](https://cyberkim8.github.io/jetops-demo/) | 📸 Instant photo delivery: guide uploader (Thai UI) → auto-check → client gallery by jet-ski number |
| [weather.html](https://cyberkim8.github.io/jetops-demo/weather.html) | 🌦 Crew weather board: live marine forecast for the Sirey→Monkey corridor, "Monkey today" verdict, client briefing |
| [dashboard.html](https://cyberkim8.github.io/jetops-demo/dashboard.html) | 🖥 Back-office ops dashboard: real-geo route map, live event feed, maintenance board, EOD report |
| [bot.html](https://cyberkim8.github.io/jetops-demo/bot.html) | 🤖 LINE ops-bot showcase: group messages → events → instant alerts → daily digest |

**Demo data only.** Photos are generated placeholders; chat messages are fabricated samples (no real names/numbers). Weather is live (Open-Meteo) where the network allows, with an offline fallback. Source of the production bot and design docs live in a private repository.
